# 🏨 Hotel Reservation Cancellation Prediction

![Python](https://img.shields.io/badge/Python-3.8+-blue.svg)
![Hospitality](https://img.shields.io/badge/Hospitality-Prediction-purple.svg)

## 📖 Overview

Classification model to predict hotel booking cancellations based on reservation details, customer behavior, and booking patterns. Helps hotels optimize inventory and revenue management.

## 🎯 Objectives

- Predict cancellation probability
- Identify cancellation patterns
- Revenue management insights
- Overbooking optimization

## 🛠️ Tech Stack

- Scikit-learn, XGBoost
- Pandas, NumPy
- Matplotlib, Seaborn

## 🚀 Usage

```bash
git clone https://github.com/adityavdn/Hotel-Reservation-Cancellation-Prediction.git
pip install -r requirements.txt
jupyter notebook
```

## 📊 Key Features

- Lead Time, Booking Changes
- Customer Type, Deposit
- Room Type, Meal Plan
- Previous Cancellations
